# ERP Student (React)

ระบบ ERP สำหรับสถานศึกษาแบบหน้าเดียว (Dashboard) พัฒนาด้วย React + Vite

## ฟีเจอร์หลัก
- แดชบอร์ดภาพรวม KPI
- โมดูลหลัก: การเงิน, นักเรียน, HR, สต็อก
- รายการงานที่ต้องติดตาม
- รองรับหน้าจอ desktop/mobile แบบ responsive

## เริ่มต้นใช้งาน
```bash
npm install
npm run dev
```

## Build สำหรับ production
```bash
npm run build
npm run preview
```
